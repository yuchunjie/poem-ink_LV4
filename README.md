# 我愛讀詩・水墨雅集 (Poem-Ink LV4)

打開瀏覽器，點擊任一首古典詩詞或名言佳句，右側會直排浮現書法文句，左側畫布則隨朗讀聲一筆筆化開水墨江山、人物與動態景致。

這是一個零後端依賴、單檔直接開啟的古典詩詞與名言佳句沉浸式學習系統。全站收錄 **24 首經典唐宋詩詞** 與 **30 句名言佳句**，配備全量預生成的 **108 個高音質神經網路語音檔**（`audio/`）與毫秒級句階時間軸（`timings.json` 且已離線內嵌），部署到 GitHub Pages 或本地 `file://` 雙擊即可直接流暢播放。

## 核心特色與升級亮點

### 1. 雙模組切換（經典詩詞 24 首 ＋ 名言佳句 30 句）
- **🏮 經典詩詞 (24)**：收錄國小與國中語文教材必背之唐宋名篇，按上、下學期各 12 首編排。
- **📜 名言佳句 (30)**：新增教育部推廣名言佳句背誦表，按上學期（一至三學月）與下學期（一至三學月）各 15 句精細分類，支援學期與學月多維度快捷篩選。

### 2. 逐句墨染跟讀動效與四階段水墨化開遮罩（4-Stage Ink Wash Masking）
- **【核心鐵則約束】畫面嚴格依唸到的句子才出現**：
  - 朗讀進行時，未讀到的句子在書法層與水墨畫布層**嚴格保持隱藏**。
  - 當朗讀推進到當前句子（`sentIdx`）時，對應的第 1~4 階段水墨場景（遠景天幕 ➔ 中景水岸 ➔ 近景人物 ➔ 點睛微粒）以淡墨暈染動效（Radial Ink Wash Masking）依序化開。
  - 配合硃砂色字句高亮，幫助學習者眼、耳、心三合一沉浸跟讀。
- **全詩完整呈現（播畢或停止）**：音訊播放結束或點擊「⏹ 停止」時，四階段遮罩平滑完全解除（`sentRevealProgress` 全數歸 1.0），全畫卷與全詩文句完整顯現，版面自適應加寬，供隨心品味全景墨韻。

### 3. Google Stitch 雙軌生動畫卷與 63 組純手繪水墨圖元庫
- **雙軌動靜融合（Hybrid Dynamic Dual-Layer）**：
  - 首發 Pilot 4 首指標名篇（《回鄉偶書》、《楓橋夜泊》、《秋夕》、《九月九日憶山東兄弟》）專屬無重複宋代水墨大師畫卷：
    - **《回鄉偶書》**：會稽煙雨遠山、石拱橋、溪岸垂柳、白髮竹杖賀知章老翁、老槐樹、好奇相望村童、茅簷裊裊炊煙。
    - **《楓橋夜泊》**：深藍霜天、沉落弦月、驚起寒鴉、赤紅江南霜楓、停泊烏篷客船、舟中暖橙漁火倒影、遠方寒山寺飛簷寶塔、同心擴散夜半鐘聲金韻。
    - **《秋夕》**：四扇仕女山水冷畫屏、銀燭台冷煙、宮女高髻窄袖執羅扇、群螢明滅綠金微光、青石水色天階、天幕璀璨銀河與牛郎織女星芒。
    - **《九月九日憶山東兄弟》**：異鄉崎嶇山麓、孤身遊子風帽旅笠、重九夕陽暖金落照、長空南飛秋雁、巍峨高嶺之巔古松兄弟共飲、懸崖近景鮮紅硃萸果串。
  - 徹底淘汰傳統機械重複的方塊帆船與山巒幾何，各篇目具備完全獨立之意境構圖！
- **63 組手繪水墨圖元庫＋自然物理微動效（100% Graceful Fallback）**：
  - 唐詩 39 組＋名言 24 組手繪圖元（原生 Canvas 2D 貝茲曲線與動態梯度）。
  - 自然物理流動：水波漣漪干涉、落櫻隨風飄灑、秋風落葉、落雪重力飄落、流雲橫移、孤雁展翅、客船隨波微晃。
  - 畫布解析度鎖定 1500 × 900 像素，底層快取 7,000 顆生宣紙纖維（PAP）、四周墨暈（VIG）與雙色流動雲霧（FOG）。

### 4. 嚴格遵循教育部審訂表之破音字校音
- 語音統一採用高品質微軟神經網路女聲（曉曉），全站 108 個音檔皆依據 **台灣教育部《國語一字多音審訂表》** 進行口播發音層校準（雙軌分離：發音層以一對一等長單音同音字強制發音，字幕與直排書法層 100% 保持漢字原字）：
  - **《回鄉偶書》**：「少小離家」之「少」讀四聲 `shào`（同「少爺」）；「兒童相見不相識」之「識」讀四聲 `shì`（同「認識」）。
  - **《出塞》**：「不教胡馬」之「教」讀平聲 `jiāo`（一聲，令、使之意）；「人未還」之「還」讀二聲 `huán`（同「歸環」）。
  - **《勸學》**：「三更燈火五更雞」之「更」讀一聲 `gēng`（同「耕」，夜間計時單位）。
  - **《金陵圖》**：「六朝如夢」之「朝」讀二聲 `cháo`（同「潮」，朝代之意）。
  - **名言《金石為開》**：「金石為開」之「為」讀二聲 `wéi`（同「行為」）。

### 5. 典藏白話賞析與字詞獨立分行
- 點擊「📖 賞析解說」展開三欄式典藏抽屜：
  - **🗣 白話說一說**：淺顯通順的故事與白話釋義。
  - **🔤 小小字詞／典故出處**：生難字詞與出處解構，**每個字詞獨立分行排版**，詞頭以硃砂紅加粗強調，閱讀層次分明。
  - **⭐ 生活領悟／記住這句**：提煉核心名句與生活哲理。
- 支援獨立的「🔊 聽解說」語音導讀，語音播放時同步高亮對應卡片。

### 6. Google Stitch 現代新宋韻與全端響應式 (RWD)
- **新宋韻宣紙水墨設計系統 (Google Stitch Distilled)**：
  - 汲取生宣米白（`#fff9ee`）、五色墨階（`#0f1011` ~ `#a1a3a6`）、金石硃砂紅（`#b03026`）、汝窯天青（`#7e9e9c`）與宋代泥金（`#b38838`），搭配線裝書雙界欄與 CJK upright 豎排字體排版。
- **全平台多端響應式佈局 (Multi-Device RWD)**：
  - **電腦大螢幕（≥ 1024px）**：左右雙欄雅集（左 58% 水墨 Canvas 舞台、右 42% 宣紙直排詩卡）。
  - **iPad / 平板端（768px ~ 1023px）**：自適應雙欄，字級以 `clamp()` 動態縮放，完整容納五言/七言絕句。
  - **手機直向（< 768px）**：上下分層舞台（Stage & Sheet Split），上部保留 16:9 水墨 Canvas 避免 70% 畫面裁切與 GPU 掉幀，下部高對比直排書法卡片；支援全新「📑 底部水墨抽屜目錄（Bottom Sheet）」，解決小螢幕橫向捲動手勢衝突。
  - **手機橫向（矮螢幕）**：左右雙欄自適應切換，懸浮控制列自動收納為側邊膠囊。
- **離線零依賴與完整設計規格**：
  - 完全免疫 CORS 限制，句階時間軸 `timings` 與音檔結構完全保留，單檔雙擊即可流暢使用。完整架構分析與審查歷程詳見 [concepts_brief.md](concepts_brief.md)。

## 本地使用與操作指南

1. **直接開啟**：
   - 雙擊根目錄下的 `index.html` 即可在任一現代瀏覽器中瀏覽、聽讀、切換。
2. **快捷鍵操作**：
   - `←`（方向鍵左）：切換上一首／上一句。
   - `→`（方向鍵右）：切換下一首／下一句。
3. **介面控制**：
   - 點選頂部「🏮 經典詩詞」或「📜 名言佳句」膠囊切換模組。
   - 點選「全部 / 上學期 / 下學期 / 學月」按鈕進行過濾。
   - 點選「🔊 朗讀」開啟逐句墨染跟讀；點選「⏹ 停止」恢復全詩完整顯現。
   - 點選右側直排書法任一句，可單句重聽並聚焦該句水墨場景。
   - 透過「語速」選單切換慢速（0.6）、適中（0.8）與快速（1.0）。
   - 勾選「自動朗讀」切換篇目時自動唱詠。
