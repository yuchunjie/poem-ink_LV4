# 我愛讀詩・水墨雅集 (Poem-Ink LV4)

打開瀏覽器，點擊任一首古典詩詞或名言佳句，右側會直排浮現書法文句，左側畫布則隨朗讀聲一筆筆化開水墨江山、人物與動態景致。

這是一個零後端依賴、單檔直接開啟的古典詩詞與名言佳句沉浸式學習系統。全站收錄 **24 首經典唐宋詩詞** 與 **30 句名言佳句**，配備全量預生成的 **108 個高音質神經網路語音檔**（`audio/`）與毫秒級句階時間軸（`timings.json` 且已離線內嵌），部署到 GitHub Pages 或本地 `file://` 雙擊即可直接流暢播放。

## 核心特色與升級亮點

### 1. 雙模組切換（經典詩詞 24 首 ＋ 名言佳句 30 句）
- **🏮 經典詩詞 (24)**：收錄國小與國中語文教材必背之唐宋名篇，按上、下學期各 12 首編排。
- **📜 名言佳句 (30)**：新增教育部推廣名言佳句背誦表，按上學期（一至三學月）與下學期（一至三學月）各 15 句精細分類，支援學期與學月多維度快捷篩選。

### 2. 逐句墨染跟讀動效（Follow-reading）
- **跟讀模式（播放中）**：朗讀進行時，未讀到的句子保持隱藏，當前正在朗讀的句子以水墨漸染動效浮現並以硃砂色高亮，讀完的句子保持優雅顯現，幫助學生集中專注力跟讀。
- **全詩完整呈現（播畢或停止）**：音訊播放結束或點擊「⏹ 停止」時，全詩所有句子平滑完整顯現，版面自適應加寬，全詩 6 欄字體端莊舒展，絕不截斷。

### 3. 63 組 1+2+3 精緻粒子與物理微動效水墨圖元庫
- **具象微動效＋物理細節＋墨分五色美學**：
  - 自然物理流動：水波漣漪干涉、落櫻隨風飄灑、秋風落葉、落雪重力飄落、流雲橫移、孤雁展翅、客船隨波微晃。
  - 大師級場景組件：寒山寺古鐘樓、江楓漁火、石橋流水、茱萸小童、重陽登高、庭院書齋翻頁古籍、碧草野火新芽。
- 畫布解析度為 1500 × 900 像素，背景疊加生宣紙纖維底紋與四角墨暈漸層，達到極致東方美學體驗。

### 4. 嚴格遵循教育部審訂表之破音字校音
- 語音統一採用高品質微軟神經網路女聲（曉曉），全站 108 個音檔皆依據 **台灣教育部《國語一字多音審訂表》** 進行口播發音層校準（雙軌分離：發音層以一對一等長單音同音字強制發音，字幕與直排書法層 100% 保持漢字原字）：
  - **《回鄉偶書》**：「少小離家」之「少」讀四聲 `shào`（同「少爺」）；「兒童相見不相識」之「識」讀四聲 `shì`（同「認識」）。
  - **《出塞》**：「不教胡馬」之「教」讀平聲 `jiāo`（一聲，令、使之意）；「人未還」之「還」讀二聲 `huán`（同「歸環」）。
  - **《勸學》**：「三更燈火五更雞」之「更」讀一聲 `gēng`（同「耕」，夜間計時單位）。
  - **《金陵圖》**：「六朝如夢」之「朝」讀二聲 `cháo`（同「潮」，朝代之意）。
  - **名言《金石為開》**：「金石為開」之「為」讀二聲 `wéi`（同「行為」）。

### 5. 典藏白話賞析與字詞獨立分行
- 點擊「📖 賞析解說」展開三欄式典藏抽屜：
  - **🗣 白話說一說**：淺顯通順的故事與白話釋義。
  - **🔤 小小字詞／典故出處**：生難字詞與出處解構，**每個字詞獨立分行排版**，詞頭以硃砂紅加粗強調，閱讀層次分明。
  - **⭐ 生活領悟／記住這句**：提煉核心名句與生活哲理。
- 支援獨立的「🔊 聽解說」語音導讀，語音播放時同步高亮對應卡片。

### 6. 離線零依賴與全平台自適應
- **完全免疫 CORS 限制**：句階時間軸 `timings` 與結構化資料已完整內嵌於 `index.html`，本地雙擊以 `file://` 開啟即可完整發聲與跟讀，不需要架設任何本機伺服器。
- **全平台響應式佈局**：支援桌面大螢幕雙欄水墨雅集、iPad / 平板橫直屏與手機移動端自適應。

## 本地使用與操作指南

1. **直接開啟**：
   - 雙擊根目錄下的 `index.html` 即可在任一現代瀏覽器中瀏覽、聽讀、切換。
2. **快捷鍵操作**：
   - `←`（方向鍵左）：切換上一首／上一句。
   - `→`（方向鍵右）：切換下一首／下一句。
3. **介面控制**：
   - 點選頂部「🏮 經典詩詞」或「📜 名言佳句」膠囊切換模組。
   - 點選「全部 / 上學期 / 下學期 / 學月」按鈕進行過濾。
   - 點選「🔊 朗讀」開啟逐句墨染跟讀；點選「⏹ 停止」恢復全詩完整顯現。
   - 點選右側直排書法任一句，可單句重聽並聚焦該句水墨場景。
   - 透過「語速」選單切換慢速（0.6）、適中（0.8）與快速（1.0）。
   - 勾選「自動朗讀」切換篇目時自動唱詠。
