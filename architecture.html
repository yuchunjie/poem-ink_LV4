零外部依賴單檔架構：雙軌時序同步與程序化向量水墨渲染引擎

雙軌容錯時序機

解決行動端與社群瀏覽器對 Web Speech API 事件吞噬、延遲觸發的硬體限制。採用雙軌並行機制：當原生朗讀事件正常回報時以精確事件推進；若事件未準時抵達，則由字元估算計時器即時接管，確保詩句高亮與水墨動畫永不中斷卡死。

程序化向量水墨庫

完全摒棄外掛肥大圖片與 GIF 動畫，使用原生 Canvas 2D 貝茲曲線與動態梯度，純程式碼演算出二十八種水墨圖元。包含山巒暈染、江流波光、孤舟微動、雨絲風動與人物神態，實現零網路依賴的極速載入。

單檔宣紙微結構緩存

初次載入時於記憶體預先渲染七千顆宣紙雜點纖維、四周暗角暈染以及日夜雙色無縫循環雲霧層。每幀渲染僅需呼叫高效 drawImage 進行筆墨合成，確保低階行動設備也能穩定以六十幀流暢運行。
